## Rules

- Never break existing REST APIs.
- Preserve all existing response formats unless instructed.
- Prefer adding services instead of modifying working code.
- Keep frontend UI unchanged unless requested.
- Write clean, typed code.
- Add logging for new backend services.
- Add unit tests for new functionality.
- Explain every modified file after implementation.

## Coding Style

- Small commits
- Small pull requests
- One feature per branch
- No unused dependencies

## Goal

Build the best AI-assisted day trading platform for Indian traders.
